# Laboratorio 1 — WDI: Implementation Plan

**Goal:** Producir un informe DOCX (≥5 páginas) con análisis descriptivo, diagnóstico y
predictivo del World Development Indicators, más un dashboard Streamlit de apoyo.

**Architecture:** Pipeline de scripts numerados y reproducibles. Cada script escribe
artefactos a disco (`data/`, `figures/`, `results.json`) y el siguiente los consume.
El informe DOCX se genera por código leyendo `results.json`, de modo que ninguna cifra
del texto se escribe a mano.

**Tech Stack:** mamba env `wdi-lab` (python 3.12), pandas, scikit-learn, statsmodels,
matplotlib/seaborn, plotly+kaleido, python-docx, streamlit.

**Spec:** diseño acordado en conversación (2026-08-30). Pregunta guía:
*¿Qué explica las brechas de esperanza de vida entre países y dónde queda Perú frente a LAC?*

## Global Constraints

- Entorno: `wdi-lab` vía mamba, definido en `environment.yml`. Nunca instalar con pip global.
- Período: 2000–2023. Objetivo: `SP.DYN.LE00.IN` (esperanza de vida al nacer).
- Unidad de análisis: país-año. Se excluyen agregados regionales del Banco Mundial
  (region == "Aggregates") del modelado; se usan solo para contexto.
- Toda cifra citada en el informe proviene de `results.json`.
- Validación del modelo con `GroupKFold` agrupando por país (evita fuga temporal/de país).
- Figuras en `figures/*.png` a 150 dpi, legibles en escala de grises.
- Idioma de todos los entregables: español.

## File Structure

| Archivo | Responsabilidad |
|---|---|
| `environment.yml` | Definición del entorno mamba |
| `src/config.py` | Constantes: indicadores, período, rutas, paleta |
| `src/01_descarga.py` | Baja API World Bank → `data/raw/*.csv` |
| `src/02_preparacion.py` | Limpieza, panel país-año, imputación → `data/processed/panel.csv` |
| `src/03_descriptivo.py` | Estadísticos, distribuciones, mapa, series → figuras + results |
| `src/04_diagnostico.py` | Correlaciones, Preston, VIF, COVID, K-means → figuras + results |
| `src/05_predictivo.py` | Modelos transversal y temporal → figuras + results |
| `src/06_informe.py` | Ensambla `informe/Laboratorio1_WDI.docx` |
| `src/utils_resultados.py` | Lectura/escritura acumulativa de `results.json` |
| `dashboard/app.py` | Dashboard Streamlit |
| `README.md` | Cómo reproducir todo |
