# Desarrollo del informe

Esta carpeta contiene los borradores que se convertirán directamente en el informe final. Cada archivo sigue el índice proporcionado por el profesor y debe completarse con resultados verificables del proyecto.

## Diferencia con `context/`

- `../context/`: guía de trabajo. Indica **cómo avanzar**, qué tareas ejecutar y qué validar.
- `./`: borradores del informe. Registra **lo realizado**, decisiones tomadas, resultados, figuras y conclusiones que se entregarán.

No se deben inventar resultados. Una sección solo se completa cuando su evidencia (código, tabla, métrica, gráfico o decisión del equipo) esté disponible.

## Orden de redacción

| Archivo | Se completa principalmente después de |
|---|---|
| `01-entendimiento-empresarial.md` | Confirmar el alcance y objetivos. |
| `02-comprension-datos.md` | Ejecutar inventario, EDA y calidad. |
| `03-preparacion-datos.md` | Construir la tabla maestra y pipeline. |
| `04-modelado.md` | Entrenar y comparar modelos. |
| `05-evaluacion.md` | Elegir modelo y analizar estabilidad. |
| `06-implementacion.md` | Generar predicciones y prototipo. |
| `07-cierre-del-informe.md` | Consolidar resultados finales. |
| `00-resumen-ejecutivo.md` | Redactar al final. |

## Convención de evidencias

Cuando se añada un resultado, indicar su procedencia: nombre de notebook/script, versión de experimento y fecha. Guardar figuras y tablas regenerables en la ubicación que el equipo defina para resultados.
